
# WADe VOX

**Web Vocabulary Extractor**

A web-based tool for extracting and managing multilingual vocabularies from HTML documents, linking terms to semantic knowledge sources such as Wikidata, DBpedia, and Schema.org.

## Overview

WADe VOX is developed as part of the **Web Application Development (WADe)** course at Alexandru Ioan Cuza University of Iași.
